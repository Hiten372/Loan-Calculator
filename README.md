# Loan Calculator

A simple and responsive **Loan Calculator** built using **HTML, CSS, and JavaScript**. This project helps users calculate their monthly EMI, total payment, and total interest based on loan amount, interest rate, and repayment duration.

## 🚀 Live Demo

👉 [View Project](https://github.com/Hiten372/Loan-Calculator)

---

## 📌 Features

- Calculate monthly EMI instantly
- Shows total payment amount
- Displays total interest payable
- Clean and user-friendly interface
- Fully responsive design
- Fast and lightweight

---

## 🛠️ Built With

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive layout
- **JavaScript** – Loan calculation logic
